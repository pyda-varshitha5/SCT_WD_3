# 🎮 Modern Tic Tac Toe

A stylish and interactive Tic Tac Toe web application built using HTML, CSS, and JavaScript.

This project was developed as part of my internship task to improve frontend development and JavaScript logic-building skills.

---

## ✨ Features

- 🧠 Play with Computer
- 👥 2 Player Mode
- 🔢 Multiple Board Sizes
  - 3×3
  - 4×4
  - 5×5
- ⏳ Countdown Animation
- 🎨 Modern Glassmorphism UI
- 📱 Responsive Design
- ⚡ Smooth Animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
